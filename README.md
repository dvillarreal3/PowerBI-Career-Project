Power BI & Data Engineering Career Project

This repository contains a 12-week guided project to build an end-to-end data platform and Power BI portfolio piece. It focuses on Azure and AWS tradeoffs while minimizing costs using local tools (DuckDB, dbt-core) and GitHub Actions CI.

Structure (initial)
- docs/               -> project documentation, governance, slide decks
- pipelines/          -> ingestion & orchestration scripts (Python, ADF templates)
- dbt/                -> dbt project (models, tests)
- powerbi/            -> .pbix samples and documentation
- ci/                 -> GitHub Actions templates
- agents/             -> agent prompts for roleplay (skill docer, PM)

See plan.md in project root for full 12-week schedule.
